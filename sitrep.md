# /sitrep — Where are we

Summarize the current chat: what we're doing, where we stand, what's next.

## Instructions

Output exactly three sections, bullet points only, 100 words max total:

- **Goal** — what this session is about (1 bullet)
- **Done** — what's been completed so far
- **Next** — remaining steps, in order

## Rules

- Bullets only. No prose, no story, no preamble.
- Hard cap: 100 words.
- Include open blockers or pending user decisions under **Next**.
- No tool calls — answer from conversation context only.
